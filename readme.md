## 📖 Sobre

Este repositório foi criado para armazenar conteúdos, exercícios e projetos desenvolvidos durante os estudos de **Banco de Dados**.

O foco é praticar conceitos fundamentais de modelagem de dados, criação de tabelas, consultas SQL e manipulação de informações em bancos de dados relacionais.

---

## 🎯 Objetivos

- 📌 Aprender conceitos de Banco de Dados Relacional
- 🗄️ Criar e modelar bancos de dados
- 🔗 Trabalhar com relacionamentos entre tabelas
- 📊 Desenvolver consultas SQL
- ⚙️ Praticar comandos DDL, DML e DQL
- 📚 Organizar projetos e exercícios para consulta futura

## 🚀 Como utilizar

Clone o repositório:

```bash
git clone https://github.com/MurilloBastos7/Banco-de-Dados.git
```

Entre na pasta:

```bash
cd Banco-de-Dados
```

Execute os scripts utilizando o banco de dados de sua preferência.

## 💡 Exemplo de Consulta

```sql
SELECT nome, idade
FROM clientes
WHERE idade >= 18
ORDER BY nome;
```
